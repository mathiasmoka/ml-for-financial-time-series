# Transformer-based attention network for stock movement prediction

This repo will contain our project for the course Machine Learning for Financial Time Series.

The project will be based on the research paper "Transformer-based attention network for stock movement prediction".

## Project execution

The steps will be:
◦ Read, understand, and discuss the paper.
◦ Illustrate the results of the paper by implementing an algorithm:
- Use a different dataset (e.g. a different asset class or time period).
- Modify a key modelling choice (e.g. a tuning parameter, cost function, or constraint).
◦ Write a report (maximum 10 pages, excluding appendices and code) and prepare slides.
